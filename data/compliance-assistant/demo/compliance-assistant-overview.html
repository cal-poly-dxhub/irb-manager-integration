Application Modes

The researcher selects a mode at session start. Each mode has its own system prompt, available tools, and UI behavior.

Co-Author

Guided section-by-section form completion. The agent fills one section at a time using the uploaded study document, then pauses and waits for the researcher to approve before continuing.

Flow: Agent fills section → summarizes → STOPS → researcher reviews/edits → clicks Approve → agent continues to next section

Tools: 6 standard tools (incl. fill_field)
Key feature: Change tracking — if researcher edits fields before approving, the diff is sent back to the agent

Review

Expert reviewer mode. The agent reads a completed form and flags compliance issues without modifying any fields. Issues appear as inline annotations on the form.

Flow: Agent reads all fields → compares against IRB guidance → flags issues (major/minor) with suggestions

Tools: 6 tools (fill_field removed, flag_issue added)
Key feature: Agent cannot fill fields — only flag problems with severity and actionable suggestions

Adapt

Resubmission helper. Pre-fills from a prior approved protocol and identifies fields that need updates for the new study.

Flow: Agent loads previous submission → pre-fills fields → identifies what needs changing → researcher confirms/modifies

Tools: 6 standard tools (incl. fill_field)
Key feature: Tracks what changed vs. original protocol

Agent Tool Set

The AI agent has 6 tools it uses to navigate and fill the form. It decides which tool to call and in what order.

get_visible_sections

Lists which form sections are currently visible based on the fields already selected. The agent calls this after filling radio/checkbox fields to discover newly unlocked sections.

get_fields_in_section

Returns all fillable fields within a section, including their type (text, radio, checkbox), whether they are required, and their current value.

get_field_guidance

Retrieves writing instructions, common mistakes, and examples from past approved submissions for a specific field. The agent calls this before writing any free-text response.

fill_field

Sets the value of a form field. For text fields, provides the written response. For radio/checkbox, selects or deselects the option. Updates appear instantly in the UI.

search_past_submissions

Semantic search over a vector database of previously approved IRB submissions. Returns similar text with relevance scores. Uses Cohere Embed v4 for embeddings.

get_form_progress

Returns a summary of how many fields have been filled across all sections. The agent uses this to track its own progress and decide what to work on next.

Before writing, the agent retrieves the writing prompt and past examples.

Common issues:
• Not naming the specific study design type
• Failing to describe how participants will be assigned to groups

Result 1 (92.4% match): 2023-377 — "This is a randomized controlled trial. Participants with Type 2 Diabetes will be randomly assigned to either a resistance training group or a control group..."

The field prompt asks me to name the specific design type and describe group assignment. Past approved submissions for RCTs typically state the design type up front, then describe randomization. I should follow that pattern."

Data Sources Powering the Agent

Three data layers give the agent institutional knowledge beyond what the uploaded document contains.

Cayuse eTemplate

The full IRB "Initial Submission" form parsed as a JSON tree. Contains 728 elements across 20 sections, with conditional visibility rules (display dependencies) between fields.

Field Writing Prompts

Custom writing guidance for each free-text field. Encodes what IRB reviewers expect: content requirements, formatting, common mistakes, and institutional policies.

Field: Inclusion Criteria
"List the specific criteria that participants must meet to be eligible..."

Common issues:
• Criteria too vague (e.g., "healthy adults")
• Omitting key requirements mentioned elsewhere

Past Submission Vectors

87 text entries from 3 previously approved TCU protocols, embedded using Cohere Embed v4 (1024-dim). Enables semantic search to find similar past responses for any field.
